# Compound Design Resources — v0.1 Readiness Audit

Date: 2026-09-09
Rubric: `CD Resource Score v0.1`
Score class: **readiness**
Status: POC calibration

## What this audit proves

This audit verifies that the first Compound Design resources have a strong, testable architecture: bounded scope, explicit routing, actionable instruction contracts, safety/provenance boundaries, and an evaluation path.

It does **not** prove empirical outcome uplift yet. Scores in this document are readiness scores. A future score may be labeled `verified` only after representative baseline comparison and repeated runs exist for the resource's primary job.

The rubric is fixed at 10 points:

- Scope & contract — 1.25
- Routing quality — 1.25
- Instruction quality — 1.25
- Outcome usefulness — 2.00
- Reliability & regressions — 1.50
- Trajectory & efficiency — 1.25
- Safety, provenance & maintainability — 1.50

A critical failure blocks promotion regardless of total score.

## Audit result

All five resources are **positive POC candidates**. None is labeled externally certified or empirically proven.

The next threshold is not a prettier 8.x number. It is the first `verified` score produced by:

`baseline → candidate → repeated runs → trajectory inspection → regression capture → independent/human grading where needed → score delta`

## POC application verification

The Compound Design POC was built on a private Git branch and successfully deployed as a Vercel preview. The deployed `/compound-design` route returned HTTP 200 and contained the expected process, resource scorecards, rubric, verifier loop and version cycle.

This deployment evidence proves build/runtime availability of the POC presentation. It does not substitute for agent/skill outcome evals.
