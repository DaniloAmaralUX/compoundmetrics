# Compound Design v0.2.1 — Evidence Infrastructure

Release type: non-runtime hardening
Evidence level: E1 unchanged
Runtime uplift: not measured

## Why this release exists

v0.2 separated construction quality from evidence. v0.2.1 makes that separation operational without spending model/API budget.

## Added

- canonical `resource-registry.json` and JSON Schema;
- deterministic `cd-lint` with mutation self-tests;
- explicit Evidence Debt;
- Learning Ledger + safe entry template;
- Wrapper Value Audit;
- AI Interaction primary-source map;
- optional LOCAL-STRESS lane for already-installed local models.

## What improved

The framework can now state, in machine-readable form, what each resource is for, where it came from, what is not its job, what evidence it has and what evidence is still missing.

A wrapper can now be removed as a successful outcome when upstream direct use is equal or better.

Real work can feed future evals without copying confidential project data or requiring extra model calls.

## What did not change

- no E2 runtime benchmark was executed;
- no runtime uplift was measured;
- no resource was promoted above E1;
- no v0.3 behavior claim is justified yet.

## Next release condition

A behavior-changing release must be earned by a reproduced failure or measured opportunity. The pre-registered E2 benchmark remains the next controlled evidence step.
