# solutions

Artifacts written by `cd-compound`, each recording a learning durable enough to survive the project.

This directory is project work memory, not framework infrastructure. It moves with the `docs_root` setting in `.compound-design/config.yaml`.

Nothing is written here unless it was earned: a decision, a constraint or a learning a future reader would otherwise have to rediscover. Most runs of `cd-compound` write no file at all.
