# frames

Artifacts written by `cd-frame`, each recording what a piece of work is actually solving.

This directory is project work memory, not framework infrastructure. It moves with the `docs_root` setting in `.compound-design/config.yaml`.

Nothing is written here unless it was earned: a decision, a constraint or a learning a future reader would otherwise have to rediscover. Most runs of `cd-frame` write no file at all.
